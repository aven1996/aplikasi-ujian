APLIKASI UJIAN SEMESTER UNTUK SEKOLAH SMK

Aplikasi ini saya buat untuk keperluan tugas akhir kuliah saya tahun 2021.
Teknologi yang saya gunakan dalam development aplikasi ini meliputi:
1. Fundamental Web (HTML, CSS, JS, PHP)
2. Bootstrap
3. JQuery
4. Library PDFObject dan PHPExcel

Fitur sistem ini meliputi:
1. Manajemen Siswa, Mapel, Nilai, Kelas, Laporan
2. Soal pilihan ganda
3. Dapat menampilkan soal dalam bentuk pdf
4. Dapat menginput soal dalam bentuk excel
5. Laporan hasil jawaban siswa dalam bentuk excel
6. Penjadwalan ujian fleksibel
